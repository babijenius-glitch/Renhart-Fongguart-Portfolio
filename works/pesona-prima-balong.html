Overview

Freelance BIM Engineer to create the complete structural model for 5 type residential housing project in Yogyakarta. The project required both accurate 3D structural modeling and a precise quantity takeoff.

This freelance engagement demonstrated the ability to work independently, manage deliverable timelines, and produce industry-standard BIM outputs using Autodesk Revit.

Scope of Work

  • Interpreted 2D structural drawings and specifications to build a 3D BIM model
  • Created comprehensive structural model in Autodesk Revit including columns, beams, and slabs
  • Performed model-based quantity takeoff for all structural elements (concrete volumes, rebar, formwork)
  • Produced Revit schedules and exported quantity reports for cost estimation
  • Reviewed model for clash detection and structural consistency

Key Deliverables

  • Complete structural 3D BIM model (.rvt)
  • Quantity takeoff report for all structural elements
  • Revit schedules exported to Excel for procurement use
